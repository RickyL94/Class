Module Descriptor

This module introduces system automation as a practical approach to improving simple organisational tasks, reducing repetitive manual work and supporting reliable digital processes in business environments. It introduces students to fundamental automation concepts, such as task analysis, basic process mapping, scripting, version control, testing, debugging, documentation and communication of automated solutions.

The module draws on introductory ideas from Business Information Systems by challenging students to consider how organisations use information, processes and digital tools to complete routine work. Students are expected to apply these ideas through hands-on automation activities using available scripting, data handling and documentation tools. Students will learn how to design and build simple automated solutions that respond to defined organisational needs, such as automated file handling, data preparation, validation and reporting. The learning in this module emphasises clear problem definition, basic requirements, repeatable development practice, error handling, testing, version-controlled artefacts and accessible explanation for technical and non-technical audiences.

This module also introduces data-handling patterns, such as structured files, tabular data, validation and simple transformation, preparing students for Databases in Trimester 2. It provides a foundation for later study in Business System Automation, Business Analytics, Cloud-Based Systems and Information System Automation.

Module Aim

This module aims to:

  • Develop an understanding of system automation and its role in improving organisational tasks, business processes and information handling.
  • Introduce basic process analysis, task decomposition, requirements capture and workflow thinking as foundations for designing useful automation solutions.
  • Develop practical skills in scripting, data handling, version control, testing, debugging and documentation using available tools and platforms.
  • Build professional habits of reliability, traceability, error handling, basic security awareness, user-focused documentation and clear communication of technical work to mixed audiences.
Six-week programmeSelect a week to expand
Week 01Automation in Organisations and Process Analysis+

Focus
The role of automation in organisational information systems, operational efficiency and routine business activity.

Identifying suitable automation opportunities in simple organisational tasks and small business processes.

Basic process mapping and workflow representation using process mapping tools, version control platforms and low-code automation platforms.

Introductory requirements capture, including problem statements, inputs, outputs, assumptions, constraints and acceptance criteria.

Week 02Scripting Fundamentals for Automation+

Focus
Scripting fundamentals using scripting languages and integrated development environments.

Core programming concepts for automation, including variables, data types, control structures and functions.

Introduce file handling and structured data concepts.

Week 03Data Handling and Task Automation+

Focus
Core programming concepts for automation, including basic validation, error handling and logging. Designing automation solutions that are understandable, maintainable and reusable.

Automating repetitive operational tasks, such as file organisation, data cleaning, data validation, simple report generation and routine information-processing activities.

Apply structured data formats such as CSV and JSON for simple automation inputs and outputs.

Basic data-handling patterns using structured files handling, tabular data, Excel-style data and simple transformations as preparation for Databases.

Week 04Version Control and Development Practices+

Focus
Version control fundamentals using repository platforms, including repositories, commits, branches, history tracking and simple collaboration workflows.

Introductory repeatable-delivery practices, including naming conventions, folder structures, simple automated checks and reproducible execution of automation artefacts.

Documentation standards for automation artefacts, including README entries, code comments, user instructions, simple runbooks and technical notes for future maintenance.

Week 05Testing, Debugging and Security+

Focus
Testing and debugging automation solutions, including functional testing, invalid input testing, exception handling and recording test evidence.

Basic security, privacy and professional issues in automation, including sensitive data, credentials, access control, accidental data loss and the limits of automation.

Week 06Professional Practice and Communication+

Focus
Communicating automation purpose, operation, limitations and business value to technical and non-technical stakeholders.

Evaluating automation solutions against organisational requirements and business needs.

Consolidation and refinement of automation artefacts, documentation and assessment evidence.

Introductory demonstration of low-code automation platforms, such as Microsoft Power Automate, to illustrate alternative approaches to workflow automation and support awareness of contemporary industry practice.
